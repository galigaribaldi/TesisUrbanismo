# TiKz_Libraries / Mapas

Mapas esquemáticos dibujados íntegramente en TikZ (sin PDFs ni PNGs de QGIS).

Uso previsto: representaciones geográficas simplificadas que no requieren
precisión cartográfica — polígonos de zona de estudio, esquemas de cobertura
conceptuales, comparativas territoriales abstractas.

Los mapas cartográficos de alta resolución producidos con Transport-gis
van en `Figures/Mapas/` y se incluyen con `\includegraphics`.
