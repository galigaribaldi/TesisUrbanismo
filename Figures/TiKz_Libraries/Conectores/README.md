# TiKz_Libraries / Conectores

Figuras de transición entre capítulos: separadores visuales, esquemas de
navegación o marcos que enlazan el cierre de un capítulo con la apertura
del siguiente.

No aportan contenido académico propio; su función es estructural y de diseño
de lectura. Deben ser figuras simples (líneas, flechas, bloques mínimos)
para no sobrecargar la composición tipográfica.
